# Gym

Website and downloads for **Gym**, a free Android lifting log that only lets you add weight once you've earned it. No account, no internet permission.

- Website: https://majid-ctrl.github.io/gym/
- Download: [latest release](https://github.com/Majid-ctrl/gym/releases/latest) (`Gym.apk`, Android 7.0+)
- Auto-updates: add this repo's URL to [Obtainium](https://github.com/ImranR98/Obtainium).
